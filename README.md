# Складно

Статический сайт с общей коллекцией рецептов. Интерфейс и рецепты разделены:
`recipes.json` — источник опубликованной коллекции, `app.js` и `style.css` — интерфейс.

## Работа с рецептами

Чтобы изменить общую коллекцию, измените `recipes.json`, выполните проверки и отправьте
изменение в `main`. На всех устройствах появится опубликованная версия.

«Подготовить рецепт» и «Подготовить правку» открывают редактор. Он скачивает JSON-черновик
и показывает его таблицу. Черновик не изменяет опубликованную коллекцию автоматически.
Для публикации его нужно добавить в `recipes.json` через GitHub или передать агенту.
Постоянный ID рецепта сохраняется при правках и используется для предотвращения дубликатов.

Избранное хранится только на текущем устройстве. Список рецептов всегда загружается
с сервера; старые локальные копии не перекрывают опубликованные исправления.
В проекте нет паролей, ключей API, исходного архива Gemini и нерецептурных переписок.

## Проверка и локальный просмотр

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```sh
npm test
npm run build
npm run preview
```

Откройте `http://127.0.0.1:8863`. Публикуется только содержимое `dist/`.

## GitHub Pages

Репозиторий публичный. Сайт публикуется через GitHub Actions после изменений в `main`.
В Settings → Pages должен быть выбран источник GitHub Actions.

Workflow Check and publish сначала проверяет код, связи рецептов и таблицы, затем
собирает `dist/` и публикует только этот каталог. Изменение рецепта не требует
правок интерфейса: достаточно обновить `recipes.json` и отправить коммит.

При Pull Request выполняются только проверки; публикация начинается после слияния
в `main`. Старую версию рецепта можно восстановить из истории Git.

## Данные

независимая кулинарная проверка. Удалять или объединять карточки можно отдельными правками.
